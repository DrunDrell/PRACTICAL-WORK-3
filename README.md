# Калькулятор та обробка даних

Простий навчальний проєкт для автоматизації базових розрахунків і структурованої обробки даних у консольному режимі.

## Встановлення
cd my-project
pip install -r requirements.txt
python main.py
Enter number 1: 10
Enter number 2: 5
Result: 15
graph TD;

    B --> C[Обробка та розрахунок];
    C --> D[Виведення результату на екран];
