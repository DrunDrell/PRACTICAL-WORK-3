# Калькулятор та обробка даних

Простий навчальний проєкт для автоматизації базових розрахунків і структурованої обробки даних у консольному режимі.

## Встановлення
Основні кроки
• Флешка: Запишіть систему на USB-накопичувач.
• БІОС: Змініть пріоритет завантаження на флешку.
• Встановлення: Дотримуйтеся підказок на екрані.
 ## використання
 Запустіть програмний модуль через термінал:
python main.py
